# PipBoy System Monitor

A Fallout Pip-Boy-inspired desktop system monitor for the Guition JC2432W328 ESP32 touchscreen display.

## Goals

- ESP32 touchscreen UI
- PC hardware monitoring over USB serial
- Pip-Boy-style interface
- Touch navigation
- Live CPU/GPU/RAM/temp/network stats

## Hardware

- Guition JC2432W328
- ESP32-WROOM-32
- 240x320 touchscreen
